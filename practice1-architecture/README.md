## Постановка задачи (Problem Statement)

**Система мониторинга доступности веб-сайтов (Uptime Monitor)** позволяет пользователям добавлять URL-адреса для отслеживания. Система автоматически проверяет доступность каждого сайта с интервалом 5 минут, записывает время ответа, HTTP-статус и отправляет уведомления в Telegram при сбое или восстановлении.

Система состоит из двух микросервисов: **API Gateway** (управление URL, историей) и **Worker** (периодическая проверка сайтов), данные хранятся в PostgreSQL.
