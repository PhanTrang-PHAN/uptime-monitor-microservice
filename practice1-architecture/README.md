

## Постановка задачи (Problem Statement)

**Система мониторинга доступности веб-сайтов (Uptime Monitor)** позволяет пользователям добавлять URL-адреса для отслеживания. Система автоматически проверяет доступность каждого сайта с заданным интервалом (например, каждые 5 минут), записывает время ответа, HTTP-статус и отправляет уведомления при обнаружении сбоя или восстановлении работы.

Пользователи могут просматривать историю проверок, статистику времени безотказной работы (uptime) и получать оповещения через Telegram. Система состоит из двух микросервисов: **API Gateway** (управление URL, историей) и **Worker** (периодическая проверка сайтов), данные хранятся в PostgreSQL.

Система должна быть масштабируемой, поддерживать мониторинг тысяч URL и предоставлять метрики для наблюдения (мониторинга).
